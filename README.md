# WebToAPI — 把网页 AI 变成本地 API。零花费，零限制。

每个月还在为 API Key 账单发愁？DeepSeek 百万上下文、Grok 无限对话、Claude 全系列……

**都不用额外花钱。**

WebToAPI 让你直接用网页版账号，就能像调用 API 一样使用这些 AI。随便聊，不限量，不审查。

---

## 能做什么

### 🐋 DeepSeek — 真 1M 上下文，无限聊
网页版百万 token 上下文全支持，不花钱买 Key 也能用满。搭配酒馆正则导入，自动过滤拒绝回复，对话永不中断。

### 🤖 Grok — 不审查，随便聊
无限请求，内容不限制。酒馆用户首选，敏感话题也能正常回复。

### 🟠 Claude — 全系列
Sonnet、Haiku、Opus，你需要的都有。

### 💠 AI Studio — 编程助手
Gemini Pro 免费使用，写代码查资料足够用。

---

## 怎么用

1. 运行程序 → 输入激活码
2. 客户端填 `http://127.0.0.1:端口/v1`
3. 开聊

支持 Chatbox、SillyTavern、OpenCat 等所有 OpenAI 兼容客户端。
